# Атлас ПК

Учебный справочник по компьютерным комплектующим. Откройте index.html в браузере. Сборка и установка пакетов не требуются.

## Страницы

- Обзор — маршруты по справочнику.
- Каталог — поиск по тексту и фильтрация по подсистеме.
- Сравнение — четыре характеристики трёх учебных процессоров.
- Сборка — проверка сокета и поколения оперативной памяти.
- Словарь — раскрывающиеся статьи о терминах.

[Открыть сайт](https://contradei.github.io/Kursovaya_Deriglazov_R.E._IKBO-22-25/).

## Проверка

В Microsoft Edge проверены пять страниц при ширине 320, 390 и 1280 пикселей, двенадцать вариантов сборки, девять пар процессоров, совмещённые фильтры и раскрытие статьи словаря. Модель совместимости ограничена двумя параметрами. Сведения об авторах изображений приведены в [перечне фотографий](assets/CREDITS.md).
