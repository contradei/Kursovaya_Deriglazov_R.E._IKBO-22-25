# Атлас ПК

Учебный справочник по компьютерным комплектующим. Откройте index.html в браузере. Сборка и установка пакетов не требуются.

## Страницы

- Обзор — маршруты по справочнику.
- Каталог — поиск по тексту и фильтрация по подсистеме.
- Сравнение — четыре характеристики трёх учебных процессоров.
- Сборка — проверка сокета и поколения оперативной памяти.
- Словарь — раскрывающиеся статьи о терминах.

[Открыть сайт](https://contradei.github.io/Kursovaya_Deriglazov_R.E._IKBO-22-25/).

## Проверка

В Microsoft Edge и Firefox проверены пять страниц при ширине 320, 390, 540, 720, 768, 900, 1280 и 1920 пикселей, двенадцать вариантов сборки, девять пар процессоров, совмещённые фильтры и раскрытие статьи словаря. Модель совместимости ограничена двумя параметрами. Сведения об авторах изображений приведены в [перечне фотографий](assets/CREDITS.md).


## Запуск и устройство проекта

После распаковки откройте index.html. Для проверки ES-модулей запустите из каталога проекта python -m http.server 8000 и откройте http://localhost:8000. На GitHub Pages работают те же модули. Для режима file браузер загружает автономный вариант offline.js. Кнопка «Тёмная тема» сохраняет выбор пользователя. Сброс в каждой форме восстанавливает начальные значения.

Основные слои ITCSS в assets/site.css: settings, generic, elements, objects, components, utilities. Примеры БЭМ: header__inner, card__media, result--invalid. Модуль main.js подключает обработчики страниц и theme.js.
